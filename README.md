SQL-Payment-Analysis

📌 Project Overview

This project analyses payment transaction data using SQL to identify payment trends, customer behavior, transaction performance, and potentially suspicious transactions.

The project demonstrates practical SQL skills such as data aggregation, filtering, grouping, subqueries, and window functions.

🎯 Objectives

- Analyse total payment transactions
- Calculate total and average payment amounts
- Identify successful and failed transactions
- Analyse payment methods
- Find top customers by payment amount
- Identify transaction trends
- Detect unusual or potentially suspicious payment activity

🛠️ Tools & Technologies

- SQL
- MySQL
- GitHub

📊 Key SQL Concepts Used

- "SELECT"
- "WHERE"
- "GROUP BY"
- "ORDER BY"
- Aggregate Functions — "SUM()", "COUNT()", "AVG()", "MIN()", "MAX()"
- "CASE WHEN"
- "JOIN"
- Subqueries
- CTEs
- Window Functions
- Date and time functions

🗂️ Dataset

The dataset contains payment transaction information such as:

- Transaction ID
- Customer ID
- Payment Date
- Payment Method
- Payment Amount
- Transaction Status

🔍 Analysis Performed

1. Payment Summary

Calculated total transactions, total payment amount, and average transaction value.

2. Payment Method Analysis

Compared transaction volume and payment amounts across different payment methods.

3. Transaction Status Analysis

Analysed successful and failed transactions to understand payment performance.

4. Customer Analysis

Identified customers with the highest transaction counts and payment amounts.

5. Transaction Analysis

Used SQL queries to identify unusual transaction patterns and potentially suspicious payments.

💡 Key Learnings

Through this project, I practiced using SQL to transform raw transaction data into meaningful business insights. I also improved my understanding of aggregation, joins, CTEs, and window functions.
